Install on device

  1. Unzip the downloaded bundle.
  2. Copy the .crosspoint folder to the root of your SD card (merge with the existing one).
  3. It writes /.crosspoint/pokemon/team.json and /.crosspoint/pokemon/sprite_<id>.bmp.
  4. Reinsert the card; assign team members to books from the device (Pokemon Party theme → Assign Pokemon) — no network needed.
