## Findings considered and rejected

(Recorded so they are not re-audited next run.)

- **WebDAV MOVE/COPY path traversal** — not exploitable. `FsHelpers::normalisePath`
  collapses `..` and clamps at root; source and destination paths use identical
  normalisation; there is no host-OS filesystem, only SD-relative paths.
- **"Notes feature orphaned from home menu"** — false positive. Notes is wired via
  `HomeMenuId::Notes` at `HomeActivity.cpp:355/370/387` with handlers at 665/698/742.
- **Settings POST JSON has no size limit** — mitigated. `SettingsHandlers.cpp:13,30`
  does a double heap-preflight returning `503` before deserialization.
- **Upload Content-Length unvalidated** — framework buffers the body; temp-file→rename
  pattern bounds impact; on the known/deferred "confirm framework behavior first" list.
- **`release.sh` sed / Python-heredoc** — inputs are hardcoded profile names, not
  user-controlled. Not worth doing.
- **CrossPointSettings singleton snapshot refactor (786 call sites)** — against-the-grain
  L refactor; flagged by the auditor itself as "not recommended as immediate fix".
